# Dataset provenance

`sample_jobs.csv` contains **300 fictional job records**, created by `scripts/generate_sample_data.py` using the Python standard library and random seed `450`. No records were scraped, purchased, or taken from a job board. Names such as "Fictional Studio 01" are invented demonstration labels.

The generated posting dates span an artificial September–October 2026 window. They are **not work dates, collection dates, or observed postings**. Salary amounts and language frequencies are arbitrary demonstration inputs. No market conclusion should be drawn from their distribution.

Regenerate the exact file from the project root:

```bash
python scripts/generate_sample_data.py
```

The default generator is deterministic and the test suite compares the regenerated bytes with the bundled file. Changing the seed or row count creates a different fictional dataset. Its schema is defined in [DATA_DICTIONARY.md](../docs/DATA_DICTIONARY.md).

The data intentionally includes jobs without salaries and a small number of non-USD ranges. These demonstrate salary coverage and exclusion behavior. Reversed ranges, duplicates, malformed CSVs, and other errors are tested with separate synthetic test fixtures.

All records carry `data_source = Synthetic sample; not real vacancies`. This label is preserved in CSV exports. Keep it when reusing the sample.

## Replacing the sample with public data

1. Find a public dataset you are permitted to download and reuse.
2. Record its exact URL, publisher, license, access date, coverage, and collection method.
3. Make a separate CSV matching the application's schema. Document any column mapping or transformations.
4. Supply explicit skill tokens; the app does not extract skills from full descriptions.
5. Keep original salary currencies and periods. Do not relabel foreign currencies as USD.
6. Upload the CSV through the dashboard. Review quality notes before making claims.

The project does not download data at runtime. Public-source provenance is intentionally blank until an actual dataset is selected:
