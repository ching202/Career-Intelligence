# Weekly practicum update templates

Use one template for each course week, 6–11. Suggested task descriptions are prompts, not completed-work claims. Enter real dates, actual time personally worked, and actual evidence links. Leave incomplete activities blank or explicitly marked pending.

Initial assistant implementation, test execution time, and generated documents do not establish student practicum hours. Describe assistance and personal contributions accurately and follow the instructor’s reporting requirements.

After publishing, replace blank GitHub fields with real commit/PR/file links. The supplied relative links already open the prepared source. Preserve the raw automated evidence unchanged.
